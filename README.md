# Retreat at home — Telegram Mini App

Static course app for the online retreat "Белые скалы". Runs inside Telegram (Mini App) or in any browser.

## Files
- `index.html`, `style.css`, `app.js` — the app (no build step).
- `course.js` — modules and lessons (generated by `build_course.py`). Do not put private video links here: the repo is public.
- `config.js` — settings: access API URL, buy link, support username.
- `function/index.js` — Yandex Cloud Function that checks channel membership and returns private video links.

## How access works
1. Buyer pays (Tilda + YooKassa or Tribute) and joins the closed channel.
2. The channel has a button that opens the Mini App.
3. The app sends Telegram `initData` to the function; the function validates it with the bot token,
   calls `getChatMember` for the channel and returns `{ok, videos}`.
4. Non-members see the "buy" screen.

With `accessApi` empty in `config.js` the app runs in open test mode with links from `course.js`.

## Review mode
Add `?review=1` to the link: every lesson gets a "Замечание по уроку" button that opens a prefilled Telegram message.

## Deploy
- App: GitHub Pages (Settings → Pages → branch `main`, folder `/`).
- Bot: create via @BotFather, `/newapp` or menu button → URL of GitHub Pages.
- Function: Node.js 18+ runtime, entry `index.handler`, env `BOT_TOKEN`, `CHANNEL_ID`, `VIDEOS_JSON`; make it public (HTTP trigger).
- Bot must be an admin of the channel for `getChatMember` to work.
